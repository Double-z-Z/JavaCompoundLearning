# META-Anti-Recommended: 拒绝清单

> 本清单定义不应纳入知识图谱的主题
> LLM在推荐学习内容时应主动检查此清单

---

## 拒绝规则

### ❌ 面试八股文

> 临时记忆，无复利价值，学完即忘

| 拒绝项 | 原因 | 替代方案 |
|--------|------|---------|
| JVM参数大全 | 背完即忘 | 理解GC原理后按需查询 |
| Redis.conf大全 | 配置查文档 | 理解原理后按需查询 |
| 并发面试题集 | 碎片化无体系 | 深入一个原理比刷100题有用 |

### ❌ 与目标无关的"有趣但无用"

> 不符合职业发展方向的知识

| 拒绝项 | 原因 | 关联GOAL |
|--------|------|---------|
| Python/Go等其他语言 | 当前专注Java路线 | GOAL-Java核心深化 |
| 前端框架深入 | 后端路线 | GOAL-SpringCloud微服务 |
| 区块链/元宇宙 | 与职业发展无关 | - |

### ❌ 重复已有知识

> 新知识必须带来至少2个新链接才创建

| 情况 | 处理方式 |
|------|---------|
| 已有笔记覆盖 | 补充链接，不新建 |
| < 2个新链接 | 先扩充现有笔记 |
| 纯重复 | 拒绝并归档到99-Archive |

## 晋升门槛（必须全部满足）

| 门槛 | 标准 | 检查方式 |
|------|------|---------|
| 实践门槛 | 必须有练习记录或项目实战 | 检查关联项目 |
| 链接门槛 | 必须链接到≥2个已有知识点 | Dataview查询 |
| 价值门槛 | 删除它能力会倒退吗？ | 人工判断 |

## LLM推荐检查流程

```
1. 检查是否在拒绝清单中
2. 检查是否满足晋升门槛
3. 检查是否已有类似笔记
4. 评估与GOAL的关联度
5. 只有全部通过才推荐创建
```
