## Gap分析原则

```
GOAL = 目标状态（what to learn）
EMRG = 当前状态（what I know）
Gap  = 差距分析
```

差距等级定义：
- 🟢 **已达标**：缺口有 EMRG 证据且 maturity=verified
- 🟡 **进行中**：缺口有 EMRG 证据但 maturity=theoretical，或有对话验证
- 🔴 **高**：缺口无 EMRG 证据且无对话验证
