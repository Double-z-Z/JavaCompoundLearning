# META-LLM上下文协议

> 本文件定义AI在知识管理中的行为规范
> 所有Skill和Agent应遵循此协议

---

## 核心原则

### 1. 知识生成优先于推荐

```
❌ 不要：推荐学这个、学那个
✅ 要：直接产出原子笔记、双向链接、代码实践
```

### 2. 触发扳机在用户手中

```
LLM只有建议权
- 涌现建议 → 用户决策
- 学习推荐 → 用户确认
- 归档删除 → 用户批准
```

### 3. 禁止时间周期触发

```
❌ 禁止：每月推荐复习、每周检查更新
✅ 正确：事件触发（完成项目/发现错误/用户要求）
```

---

## LLM权限边界

| 行为 | 权限 |
|------|------|
| 创建原子笔记 | ✅ 自动 |
| 创建EMRG | ❌ 建议 |
| 删除/归档笔记 | ❌ 建议 |
| 更新mastery分数 | ✅ 自动 |
| 创建GOAL条目 | ❌ 建议 |
| 修改GOAL内容 | ❌ 建议 |
| 更新涌现日志 | ✅ 自动 |

---

## 对话前必读

读取顺序（优先级）：
1. `.agent/_system/META-Index-知识模型.md` - 当前状态快照
2. `.agent/goals/GOAL-Index.md` - 当前GOAL优先级
3. `.agent/_system/META-Anti-Recommended.md` - 避免推荐已拒绝项

## Skill触发规则

| Skill | 触发条件 | 输出位置 |
|-------|---------|---------|
| 整理笔记 | 讨论完核心概念/完成练习/用户说整理 | 02-Knowledge/ |
| 项目拆解 | 用户想做新项目 | 01-Projects/ |
| 评估触发 | 完成项目/达成里程碑 | 03-Practice/assessment/ |
| 学习推荐 | 用户说开始学习/新对话开始 | profile.md |
| 错误归档 | 代码出错/发现误区 | 03-Practice/mistakes/ |
| 强化练习 | 错误归档后/用户要求 | 03-Practice/drills/ |

---

## 涌现识别规则

当发现以下情况时，应在 META-涌现触发器日志 中记录：

| 触发类型 | 检测条件 | 建议格式 |
|---------|---------|---------|
| 密度阈值 | Tag下≥5笔记 + ≥3链接 | 创建EMRG建议 |
| 链接熵增 | 笔记被≥3不同MOC引用 | 创建交叉EMRG建议 |
| 冲突浮现 | 同一概念矛盾定义 | 标记并提示 |
| 复盘触发 | 项目完成/故障恢复 | 引导归档 |

---

## 知识关联要求

每创建一个原子笔记，必须同时：
1. 链接到≥2个已有知识点
2. 说明关联原因
3. 在对应EMRG中注册
