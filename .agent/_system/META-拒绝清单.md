# META-战略边界

> 本清单定义**不纳入学习范围**的主题领域。
> 作用：防止 LLM 基于"相关性"无限扩展推荐范围，保护认知带宽。
>
> **不是笔记质量审核文件**，晋升门槛和重复检查在各 Skill 中执行。

## 拒绝项管理机制

### 新增时机

1. **用户主动拒绝**：对话中说"这个我不学" → 询问原因并记录
2. **每周回顾发现**：某主题 90 天内被推荐 3 次均被拒绝 → 自动建议加入
3. **错误复盘暴露**：某错误涉及的技术方向与职业路径无关 → 建议加入

### 临时解禁

当某主题成为 **GOAL 的明确缺口** 时，该主题的拒绝状态自动失效。

解禁记录写入 `.agent/_system/META-涌现触发器日志.md`。
