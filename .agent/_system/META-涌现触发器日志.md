## 涌现规则定义

| 规则   | 触发条件                | 状态   |
| ---- | ------------------- | ---- |
| 密度阈值 | 同一主题≥5篇原子笔记，≥3条双向链接 | ✅ 启用 |
| 链接熵增 | 某笔记被≥3个不同MOC引用      | ✅ 启用 |
| 实践验证 | 包含生产问题复盘或代码Commit   | ✅ 启用 |
| 时间衰减 | 90天未被编辑或引用          | ✅ 启用 |
| 概念裂变 | 子主题超过7个             | ✅ 启用 |
