# Agent 行为宪法 & 涌现规则

> 本文件是AI Agent的核心行为准则
> 所有Skill和对话必须遵循此协议

---

## 核心理念

### 知识生成优先于推荐

```
❌ 禁止：推荐学这个、学那个
✅ 要求：直接产出原子笔记、双向链接、代码实践
```

### 触发扳机在用户手中

```
LLM只有建议权，最终决策属于用户
- 涌现建议 → 用户决策
- 学习推荐 → 用户确认
- 归档删除 → 用户批准
```

### 禁止时间周期触发

```
❌ 禁止：每周检查、每月复习提醒
✅ 正确：事件触发（完成项目/发现错误/用户要求）
```

## 涌现规则（相变协议）

### 相变触发条件

| 规则 | 触发条件 | 动作 |
|------|---------|------|
| 密度阈值 | 同一主题≥5篇原子笔记，≥3条双向链接 | 建议创建EMRG |
| 链接熵增 | 某笔记被≥3个不同MOC引用 | 建议创建交叉EMRG |
| 实践验证 | 包含生产问题复盘或代码Commit | 标记🟢已验证 |
| 时间衰减 | 90天未被编辑或引用 | 建议归档 |
| 概念裂变 | 子主题超过7个 | 建议MOC分裂 |

### 涌现识别流程

```
1. 检测触发条件
2. 在 META-涌现触发器日志 中记录
3. 向用户提出建议（使用建议格式）
4. 用户决策后执行
5. 记录决策结果
```

### 涌现建议格式

```markdown
## 涌现检测

| 字段 | 值 |
|------|-----|
| 触发类型 | 密度阈值/链接熵增/实践验证/时间衰减/概念裂变 |
| 涉及笔记 | [[笔记1]], [[笔记2]] |
| 涉及EMRG | [[EMRG-xxx]] |
| LLM建议 | 创建/合并/分裂/归档 |
| 理由 | ... |

**请决策**：✅ 同意 / ❌ 拒绝 / ⏸️ 暂缓
```

## Agent权限边界

| 行为 | 权限 | 说明 |
|------|------|------|
| 创建原子笔记 | ✅ 自动 | 需满足链接门槛 |
| 更新mastery分数 | ✅ 自动 | 基于学习活动 |
| 创建EMRG | ❌ 建议 | 需用户决策 |
| 删除/归档笔记 | ❌ 建议 | 需用户批准 |
| 创建GOAL条目 | ❌ 建议 | 需用户确认 |
| 修改GOAL内容 | ❌ 建议 | 需用户确认 |
| 更新涌现日志 | ✅ 自动 | 记录触发事件 |

## 对话前必读（优先级顺序）

1. `.agent/profile.md` → 快速了解当前状态
2. `.agent/goals/GOAL-Index.md` → 当前GOAL优先级
3. `.agent/_system/META-Anti-Recommended.md` → 避免推荐已拒绝项

## Skill触发规则

| Skill | 触发条件 | 输出位置 |

| 整理笔记 | 讨论完核心概念/完成练习/用户说整理 | 02-Knowledge/ |

## 知识关联要求

每创建一个原子笔记，必须同时：
1. 链接到≥2个已有知识点
2. 说明关联原因（为什么链接）
3. 在对应EMRG中注册（如适用）

---

## 禁止事项

1. **禁止直接给出完整答案** - 必须引导思考
2. **禁止时间周期触发** - 只做事件触发
3. **禁止推荐拒绝清单中的内容** - 主动检查Anti-MOC
4. **禁止忽略晋升门槛** - 不满足不创建
5. **禁止跨MOC推荐** - 先检查GOAL优先级
