# 学习推荐

> **触发时机**:
> - 用户说"开始今日学习"
> - 每次新建对话时（作为开场分析）
> - 完成一个主题后
>
> **数据来源**:
> - `.agent/profile.md` - 学习者画像、已掌握知识点、mastery分数
> - `.agent/goals/GOAL-Index.md` - GOAL优先级
> - `.agent/_system/META-Gap-诊断矩阵.md` - Gap分析（新增）
> - `.agent/_system/META-Anti-Recommended.md` - 拒绝清单（新增）
> - `02-Knowledge/` - 知识库扫描
> - `03-Practice/mistakes/` - 错误模式
> - `04-Maps/EMRG-*.md` - 主题地图
> - `01-Projects/` - 进行中的项目

## 工作流程

### 1. 数据分析

读取并分析以下数据：

```
.agent/profile.md
├── 已掌握知识点及mastery分数
├── 当前进行中的项目
├── 历史学习数据（学习频率、偏好）
├── 当前学习计划（用户上次的决定）
└── 拒绝清单（Anti-MOC）

.agent/goals/GOAL-Index.md
├── GOAL优先级列表（P0/P1/P2）
└── 当前进行中的GOAL

.agent/_system/META-Gap-诊断矩阵.md  # 新增
├── P0 GOAL的缺口分析
├── 学习策略建议
└── 决策状态

02-Knowledge/<主题>/concepts/
├── 每个概念的mastery分数
├── 最后更新时间
└── 入链/出链数量（网络密度）

03-Practice/mistakes/
├── 活跃错误模式（未完全掌握）
└── 错误发生频率

04-Maps/EMRG-*.md
├── 各主题学习进度
└── 核心概念掌握状态

01-Projects/
└── 进行中的项目及当前Phase
```

### P0 GOAL进度（Gap矩阵）

|------|------|---------|------|

| [[GOAL-Redis深入]] | 进行中 | 数据结构底层 | ⏳ |
| [[GOAL-SpringCloud微服务]] | 待开始 | 原理空白 | ⏳ |

|-----|---------|---------|------|

### 3. Gap矩阵过滤后的推荐（新增）

**过滤规则**：推荐的任何内容必须经过以下检查

```
1. 检查是否在拒绝清单中？
   → 如果是，不推荐

2. 检查是否与P0 GOAL相关？
   → 优先推荐与P0 GOAL缺口的知识

3. 检查是否满足晋升门槛？
   → 实践门槛、链接门槛、价值门槛

4. 检查是否是知识孤岛？
   → 优先推荐能建立链接的知识
```

### 4. 生成学习推荐

基于数据分析 + Gap过滤，生成3个选项：

```markdown
🎯 **今日学习推荐**（基于Gap矩阵）

#### 选项1: 【继续P0 GOAL缺口】（推荐度: ⭐⭐⭐⭐⭐）
**内容**: 完成 [[GOAL-Java核心深化]] 的 [[epoll机制]] 学习
**理由**:
- 与P0 GOAL[[GOAL-Java核心深化]]的主要缺口匹配
- 查看 [[META-Gap-诊断矩阵]]: 当前进度40%，epoll是下一个目标
- 该知识点与已有 [[NIO-Selector]] 强关联
**预计耗时**: 1.5小时
**产出**: 原子笔记 + 更新Gap矩阵

#### 选项2: 【复习巩固】（推荐度: ⭐⭐⭐⭐）
**内容**: 复习 [[线程池原理]]
**理由**:
- mastery=55，接近遗忘临界点
- 该概念是 [[GOAL-Java核心深化]] 的核心组成部分
- 查看 [[META-Gap-诊断矩阵]]: 线程池是Java并发的基石
**建议动作**: 完成1个线程池练习

#### 选项3: 【探索新知】（推荐度: ⭐⭐⭐）
**内容**: 学习 [[Netty ByteBuf]]
**理由**:
- 与已掌握的 [[NIO-Buffer]] 高度关联
- 是 [[GOAL-SpringCloud微服务]] 的前置知识（Netty是RPC框架基础）
- 网络分析显示这是NIO→Netty学习路径的下一个节点
**预计耗时**: 1小时

⚠️ **学习预警**
- 学习 [[epoll]] 时注意: 你曾犯错 [[MISTAKE-004]]（Selector操作错误）
- 建议提前复习错误档案
```

## 推荐算法（更新）

### 推荐度计算因素

| 因素 | 权重 | 说明 |
|-----|------|------|
| **P0 GOAL缺口匹配** | 35% | 优先填补P0 GOAL的缺口（新增） |
| 项目连续性 | 25% | 有进行中的项目优先 |
| 艾宾浩斯遗忘曲线 | 15% | 接近遗忘临界点的优先复习 |
| 知识关联度 | 10% | 与最近学习关联度高的优先 |
| 网络密度 | 10% | 知识孤岛优先连接 |
| 前置依赖 | 5% | 项目前置知识优先 |

### Gap过滤规则（新增）

```
推荐任何内容前，必须检查：

1. Anti-MOC过滤
   ❌ 如果在 META-Anti-Recommended.md 中 → 不推荐

2. P0 GOAL优先
   ✅ 如果与P0 GOAL缺口匹配 → 优先级提升

3. 晋升门槛检查
   ❌ 如果不满足实践/链接/价值门槛 → 不推荐创建笔记
   ✅ 如果满足 → 正常推荐

4. 决策状态检查
   ⏳ 如果GOAL状态为"暂缓" → 降低优先级
   ❌ 如果GOAL状态为"放弃" → 不推荐
```

### 预警规则

自动触发预警：
- mastery < 50 且 7天未复习 → "即将遗忘，建议复习"
- 历史错误模式匹配 → "注意避免 [[MISTAKE-XXX]]"
- 知识孤岛（入链+出链 < 2）→ "建议建立更多关联"
- P0 GOAL缺口知识 → "这是当前P0优先项"
