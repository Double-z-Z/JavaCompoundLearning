### 3. Gap矩阵过滤后的推荐

**数据来源**：

- 拒绝清单 → `.agent/profile.md #拒绝清单` + `.agent/_system/META-Anti-Recommended.md`
- GOAL缺口 → `.agent/_system/META-Gap-诊断矩阵.md`（由每周回顾Skill生成，本Skill只读取）
- GOAL deadline → 各 `GOAL-*.md` 的 frontmatter.deadline

**过滤规则**：推荐的任何内容必须经过以下检查

```
1. 拒绝清单检查
   → 来源: profile.md #拒绝清单 + META-Anti-Recommended.md
   → 如果在拒绝清单中 → 不推荐

2. GOAL deadline检查
   → 来源: GOAL-*.md frontmatter.deadline
   → 如果 deadline 已过期 → 标红提示"已过期，建议归档或延期"

3. 检查是否与P0 GOAL相关？
   → 优先推荐与P0 GOAL缺口的知识

4. 检查是否满足晋升门槛？
   → 实践门槛、链接门槛、价值门槛

5. 检查是否是知识孤岛？
   → 优先推荐能建立链接的知识
```

## 推荐算法（更新）

### 推荐度计算因素

| 因素              | 权重  | 说明                 |
| --------------- | --- | ------------------ |
| **P0 GOAL缺口匹配** | 40% | 优先填补P0 GOAL的缺口 |
| 项目连续性           | 25% | 有进行中的项目优先          |
| 知识关联度           | 15% | 与最近学习关联度高的优先       |
| 网络密度            | 15% | 知识孤岛优先连接           |
| 前置依赖            | 5%  | 项目前置知识优先           |

### Gap过滤规则

**数据来源说明**：

- Gap 矩阵由「每周回顾」Skill 生成并写入 `.agent/_system/META-Gap-诊断矩阵.md`
- 本 Skill 只读取，不生成

```
推荐任何内容前，必须检查：

1. Anti-MOC过滤
   ❌ 如果在 META-Anti-Recommended.md 中 → 不推荐

2. GOAL deadline检查
   → 来源: GOAL-*.md frontmatter.deadline
   → 如果 deadline 已过期 → 🔴 标红并提示"已过期，建议归档或延期"

3. P0 GOAL优先
   ✅ 如果与P0 GOAL缺口匹配 → 优先级提升

4. 晋升门槛检查
   ❌ 如果不满足实践/链接/价值门槛 → 不推荐创建笔记
   ✅ 如果满足 → 正常推荐

5. 决策状态检查
   ⏳ 如果GOAL状态为"暂缓" → 降低优先级
   ❌ 如果GOAL状态为"放弃" → 不推荐
```

### 预警规则

自动触发预警：

- 历史错误模式匹配 → "注意避免 \[\[MISTAKE-XXX]]"
- 知识孤岛（入链+出链 < 2）→ "建议建立更多关联"
- P0 GOAL缺口知识 → "这是当前P0优先项"
