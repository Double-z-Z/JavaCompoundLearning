# 每周回顾

> **触发条件**:
> - 用户说"每周回顾"
> - 每周五自动触发（由用户手动触发，非时间自动）
> - 里程碑达成后
>
> **核心原则**:
> - 时间触发被禁止，此Skill由用户主动触发
> - LLM只有建议权，最终决策属于用户
>
> **数据来源**:
> - `.agent/_system/META-Index-知识模型.md` - 当前状态快照
> - `.agent/_system/META-涌现触发器日志.md` - 涌现记录
> - `.agent/goals/GOAL-*.md` - GOAL进度
> - `04-Maps/EMRG-*.md` - EMRG健康度

---

## 苏格拉底式四问法

### 问题1: 方向之问

> **"删除这个EMRG/GOAL，能力会倒退吗？"**

```
扫描所有EMRG和进行中的GOAL：

对于每个EMRG：
- 这个主题的知识点还能被其他EMRG覆盖吗？
- 如果删除，是否有知识会变成孤儿？

对于每个GOAL：
- 这个GOAL还符合职业目标吗？
- 完成它对晋升有意义吗？
```

#### 输出格式

```markdown
## 方向之问

| 名称 | 删除影响 | 保留理由/归档理由 |
|------|---------|------------------|
| EMRG-并发编程 | 高 | Java核心能力必需 |
| GOAL-SpringCloud微服务 | 高 | 简历明确要求 |
| EMRG-xxx | 低 | 可合并到EMRG-yyy |
```

---

### 问题2: 密度之问

> **"哪些笔记最近7天被引用过？"**

使用Dataview查询：

```dataview
TABLE file.mtime as "最后更新"
FROM ""
WHERE file.mtime > date(today) - dur(7 days)
SORT file.mtime DESC
LIMIT 20
```

#### 输出格式

```markdown
## 密度之问

### 活跃笔记（7天内更新）
| 笔记 | mastery | 更新时间 |
|------|---------|---------|
| [[NIO-Selector]] | 70 | 2天前 |
| [[Redis-Cluster]] | 85 | 3天前 |

### 沉默笔记（30天未更新）
| 笔记 | mastery | 最后更新 |
|------|---------|---------|
| [[反射机制]] | 20 | 45天前 |

⚠️ **决策**：[[反射机制]] 是否归档到99-Archive？
```

---

### 问题3: 分裂之问

> **"LLM推荐的新主题是否纳入？"**

检查涌现日志：

```markdown
## 分裂之问

### 待评估的涌现触发（来自 META-涌现触发器日志）

| 触发类型 | 涉及内容 | LLM建议 | 用户决策 |
|---------|---------|---------|---------|
| 密度阈值 | Tag#缓存下有6篇笔记 | 创建EMRG-缓存 | ⏳ |
| 链接熵增 | [[缓存行伪共享]]被3个EMRG引用 | 创建交叉EMRG | ⏳ |

### Anti-MOC检查

| 推荐主题 | 是否在拒绝清单 | 原因 |
|---------|--------------|------|
| JVM参数大全 | ✅ 是 | 面试八股，无复利价值 |
| Python学习 | ✅ 是 | 非Java路线 |
```

---

### 问题4: 迷失之问

> **"能不看笔记画出拓扑结构吗？"**

```
要求用户或AI根据记忆，画出当前知识网络的拓扑结构：

```
知识网络拓扑（根据记忆）

并发编程 --→ futex
    ↓
线程池 --→ LongAdder
    ↓
NIO --→ Buffer
    ↓
Netty
```

然后对比实际图谱：
- 是否有遗漏的强关联？
- 是否有从未注意到的跨域连接？
```

## 四阶段回顾流程

### Stage 1: 数据收集

```
1. 读取 .agent/_system/META-Index-知识模型.md
2. 扫描所有 EMRG 和 GOAL 的状态
3. 运行 Dataview 查询获取活跃/沉默笔记
4. 检查 META-涌现触发器日志 的待决策项
```

### Stage 2: 四问执行

```
按顺序执行四问：
1. 方向之问 → 保留/归档决策
2. 密度之问 → 复习/归档决策
3. 分裂之问 → 涌现触发决策
4. 迷失之问 → 知识网络校正
```

### Stage 3: 决策记录

```markdown
## 本周回顾决策

| 类别 | 决策项 | 行动 |
|------|--------|------|
| 归档 | [[反射机制]] | 移至99-Archive |
| 涌现 | 创建EMRG-缓存 | ✅ 同意 |
| 复习 | [[沉默笔记列表]] | 下周优先复习 |
| 更新 | GOAL-Java核心深化 | mastery 65→70 |
```

### Stage 4: 更新文件

根据决策执行：
- 归档笔记 → 移至 99-Archive/
- 涌现触发 → 更新 META-涌现触发器日志.md
- GOAL更新 → 更新对应 GOAL 文件
- 复习计划 → 更新 META-Index-知识模型.md
