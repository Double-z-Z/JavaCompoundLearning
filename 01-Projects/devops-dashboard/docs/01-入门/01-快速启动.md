# DevOps Dashboard — 快速启动指南

> 从零到 MCP Server 运行 + Trae 连接的完整流程

---

## 1. 环境准备

### 1.1 前置条件

| 组件 | 版本要求 | 验证命令 |
|------|---------|---------|
| **JDK** | 17+ | `java -version` |
| **Maven** | 3.8+ | `./mvnw -v` |
| **wrk** (可选) | 最新版 | `wrk --version` |
| **hey** (可选) | 最新版 | `hey --version` |

### 1.2 确认网络拓扑

确保以下节点可达（根据你的 `hosts.yml` 配置调整 IP）：

```bash
# 测试 SSH 连通性
ssh -i ~/.ssh/id_rsa dev@10.0.0.102 "echo ok"    # MCP Host
ssh -i ~/.ssh/id_rsa test@10.0.0.103 "echo ok"    # Target Host
ssh -i ~/.ssh/id_rsa loadgen@10.0.0.104 "echo ok"  # Loadgen Host

# 确认压测工具已安装
ssh loadgen@10.0.0.104 "which wrk && which hey"
```

## 2. 配置 hosts.yml

编辑 `src/main/resources/hosts.yml`，确保与你的实际环境一致：

```yaml
hosts:
  - id: pve-01
    type: pve-hypervisor
    label: "PVE 虚拟化宿主机"
    network_zone: lan-10.0.0
    capabilities: [vm]
    roles: []
    resources:
      cpu_total: 32
      mem_total_mb: 128000

  - id: vm-fedora-dev
    type: vm
    parent: pve-01
    label: "Fedora 开发环境 (MCP Server)"
    network_zone: lan-10.0.0
    capabilities: [docker, native]
    roles: [mcp-host, target]
    resources:
      cpu_total: 8
      mem_total_mb: 16384
    access:
      ssh: 10.0.0.102
      port: 22
      user: dev
      key_path: /home/dev/.ssh/id_rsa

  - id: vm-loadgen-01
    type: vm
    parent: pve-01
    label: "专用压测机"
    network_zone: lan-10.0.0
    capabilities: [native]
    roles: [loadgen]
    resources:
      cpu_total: 8
      mem_total_mb: 8192
    access:
      ssh: 10.0.0.104
      port: 22
      user: loadgen
      key_path: /home/dev/.ssh/id_rsa
    loadgen_tools: [wrk, hey, ab]
```

> **关键检查项**: IP 地址、SSH 用户、SSH key 路径必须与实际环境匹配。

```bash
./mvnw clean package -DskipTests

ls -la target/devops-dashboard-*.jar
```

## 4. 启动 MCP Server

### 方式 A：独立进程模式（推荐）

MCP Server 作为独立 Spring Boot 应用运行，端口 **8081**。

```bash
# 前台运行（调试用）
java \
  -Dspring.profiles.active=mcp \
  -Dserver.port=8081 \
  -jar target/devops-dashboard-0.0.1-SNAPSHOT.jar

# 后台运行（生产用）
mkdir -p logs
nohup java \
  -Dspring.profiles.active=mcp \
  -Dserver.port=8081 \
  -jar target/devops-dashboard-0.0.1-SNAPSHOT.jar \
  > logs/mcp-server.log 2>&1 &

# 记录 PID
echo $! > mcp-server.pid
```

### 方式 B：同进程模式（简化部署）

MCP Server 与主应用共用一个 JVM，MCP SSE 暴露在 **8080/mcp/sse**。

```bash
# 1. 修改 application.yml，追加：
# spring.profiles.include: mcp

# 2. 启动主应用（自动包含 MCP）
java -jar target/devops-dashboard-0.0.1-SNAPSHOT.jar

# 此时访问路径：
# MCP SSE: http://localhost:8080/mcp/sse
```

## 5. Trae 配置连接

### 5.1 打开 Trae MCP 面板

- **IDE 模式**: 右上角「设置」→ 左侧「MCP」
- **SOLO 模式**: 对话面板右上角「设置」→ 「MCP」

### 5.2 添加 MCP Server

点击「添加」→「手动添加」，粘贴：

```json
{
  "mcpServers": {
    "devops-dashboard": {
      "type": "sse",
      "url": "http://10.0.0.102:8081/mcp/sse"
    }
  }
}
```

### 5.3 验证连接

- 列表中应显示 `devops-dashboard`，状态为绿色 ✅
- 如果红色 ❌，见[常见问题](#7-常见问题速查)

## 6. 验证命令

### 6.1 验证 MCP Server 启动

```bash
# 本地测试 SSE 端点
curl -N http://localhost:8081/mcp/sse

# 远程测试（从开发机）
curl -N http://10.0.0.102:8081/mcp/sse

# 应返回 SSE 流式响应（持续连接，Ctrl+C 退出）
```

### 6.2 验证日志输出

```bash
tail -f logs/mcp-server.log | grep -E "Started|MCP|Registered"

# 期望看到：
# "DevOps Dashboard MCP Server started on port 8081"
# "Registered X tools, Y resources, Z prompts"
```

在 Trae 中输入：

```
我现在有哪些可用的主机？
```

AI 应调用 `hosts://topology` Resource 并返回你的节点列表。

## 7. 常见问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| **Trae 显示 ❌ Connection refused** | MCP Server 未启动 | 检查 `ps aux \| grep devops-dashboard` |
| **Trae 显示 ❌ Timeout** | 防火墙拦截 | `sudo firewall-cmd --add-port=8081/tcp` |
| **Trae 显示 ❌ 404 Not Found** | SSE 路径错误 | 检查 `application-mcp.yml` 中 `mcp.server.path` |
| **Port 8081 already in use** | 端口占用 | 修改 `server.port` 或 `kill -9 <PID>` |
| **Failed to load hosts.yml** | YAML 格式错误 | 检查缩进、确认无 Tab 字符 |
| **Host not found: pve-01** | parent 引用不存在 | 确保 `parent` 字段指向已定义的 host id |
| **SSH 连接失败** | Key 未分发或权限错误 | 检查 `~/.ssh/id_rsa` 权限为 600 |

### 防火墙命令速查

```bash
# 开放端口
sudo firewall-cmd --add-port=8081/tcp --permanent
sudo firewall-cmd --reload

# 验证
sudo firewall-cmd --list-ports
```

## 8. 停止 MCP Server

```bash
# 优雅停止（推荐）
kill -15 $(cat mcp-server.pid)

# 强制停止（如果优雅停止失败）
kill -9 $(cat mcp-server.pid)

# 或直接查找进程
ps aux | grep devops-dashboard
kill -15 <PID>
```
