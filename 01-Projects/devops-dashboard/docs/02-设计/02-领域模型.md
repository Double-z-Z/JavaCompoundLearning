# 领域模型

> 当前版本领域模型：6 个聚合根 + 领域服务 + 不变量规则。
> 前置阅读: [00-术语表.md](../00-术语表.md)

---

## 1. 聚合根总览

| 聚合根                   | 身份标识            | 核心职责             | 状态           |
| --------------------- | --------------- | ---------------- | ------------ |
| **Host**              | `HostId`        | 基础设施节点管理，角色与拓扑维护 | 稳定           |
| **Environment**       | `EnvironmentId` | 运行空间生命周期与资源分配    | 状态机已精化       |
| **DeployPipeline**    | `PipelineId`    | 部署流水线编排（首选入口）    | V3 新增        |
| **LogAggregate**      | `LogQueryId`    | 日志聚合与排查（唯一合法日志源） | V3 新增        |
| **ExperimentSession** | `SessionId`     | 实验全流程管理与证据聚合     | 保留，Tool 暴露延后 |
| **Evidence**          | `EvidenceId`    | 结构化证据存储与溯源       | 保留，Tool 暴露延后 |

## 2. Host（主机节点）— 聚合根

**身份标识**: `HostId`

**核心职责**: 管理基础设施的物理/逻辑节点，维护角色、拓扑和能力声明。

### 2.1 领域模型

```java
package devops.dashboard.domain.host;

public class Host {
    private final HostId id;
    private final HostType hostType;          // PVE_HYPERVISOR, VM, BARE_METAL, LOCAL
    private final HostId parentId;            // null for root nodes
    private final String label;
    private final NetworkZone networkZone;
    private final Set<Capability> capabilities; // DOCKER, NATIVE, VM
    private final Set<HostRole> hostRoles;    // MCP_HOST, TARGET, LOADGEN
    private final ResourceCapacity resources;
    private final AccessInfo access;
    private final HostStatus status;
    private final Instant lastHeartbeat;

    public boolean isTarget() { return hostRoles.contains(HostRole.TARGET); }
    public boolean isLoadgen() { return hostRoles.contains(HostRole.LOADGEN); }
    public boolean isMcpHost() { return hostRoles.contains(HostRole.MCP_HOST); }
    public boolean supportsDocker() { return capabilities.contains(Capability.DOCKER); }
    public boolean supportsNative() { return capabilities.contains(Capability.NATIVE); }
    public boolean hasParent(HostId candidate) { return candidate.equals(this.parentId); }
    public boolean isSibling(Host other) {
        if (this.parentId == null || other.parentId == null) return false;
        return this.parentId.equals(other.parentId);
    }
}
```

### 2.2 枚举定义

```java
public enum HostType {
    PVE_HYPERVISOR,   // PVE 宿主机，parent=null
    VM,               // 虚拟机，parent 指向 PVE_HYPERVISOR
    BARE_METAL,       // 裸金属，parent=null
    LOCAL             // 本地开发机，parent=null
}

public enum HostRole {
    MCP_HOST,         // 运行 MCP Server 进程
    TARGET,           // 可部署环境/服务
    LOADGEN           // 可执行压测
}

public enum Capability {
    DOCKER,           // 运行 Docker Daemon
    NATIVE,           // 可直接运行进程/二进制
    VM                // 可创建虚拟机（仅 PVE_HYPERVISOR）
}
```

## 3. Environment（环境）— 聚合根

**身份标识**: `EnvironmentId`

**核心职责**: 管理运行空间的生命周期和资源分配。

### 3.1 领域模型

```java
package devops.dashboard.domain.environment;

public class Environment {
    private final EnvironmentId id;
    private final HostId hostId;
    private final EnvironmentType environmentType;  // DEV, TEST, STAGING, PROD, EXPERIMENT
    private final IsolationType isolationType;      // DOCKER, NATIVE
    private final String runtimeConstraint;         // "docker:26.0", "openjdk:21-jre-slim"
    private final EnvironmentStatus status;
    private final List<ServiceInstance> services;
    private final ResourceQuota resourceQuota;
    private final LifecyclePolicy lifecyclePolicy;
    private final Map<String, Endpoint> accessEndpoints;
    private final Instant createdAt;

    public void transitionTo(EnvironmentStatus newStatus) {
        if (!VALID_TRANSITIONS.get(this.status).contains(newStatus)) {
            throw new InvalidEnvironmentTransitionException(
                String.format("当前状态为 %s，不允许转换为 %s。必须先执行 %s。",
                    this.status, newStatus, suggestPrecondition(newStatus))
            );
        }
        this.status = newStatus;
    }
}
```

### 3.2 枚举定义

```java
public enum EnvironmentType {
    DEV("开发环境", "dev"),
    TEST("测试环境", "test"),
    STAGING("预发布环境", "staging"),
    PROD("生产环境", "prod"),
    EXPERIMENT("实验环境", "experiment");
}

public enum IsolationType {
    DOCKER("docker", "Docker 容器隔离"),
    NATIVE("native", "原生进程隔离");
}

public enum EnvironmentStatus {
    CREATING("创建中"),
    READY("就绪，允许部署"),        // V3 新增
    DEPLOYING("部署锁定中"),         // V3 新增
    RUNNING("运行中"),
    ERROR("异常，需排查"),           // V3 新增，替代 FAILED
    DESTROYED("已销毁");
}
```

### 3.3 状态转换规则

```java
private static final Map<EnvironmentStatus, Set<EnvironmentStatus>> VALID_TRANSITIONS = Map.of(
    CREATING,  Set.of(READY, ERROR),
    READY,     Set.of(DEPLOYING, DESTROYED),
    DEPLOYING, Set.of(RUNNING, ERROR),
    RUNNING,   Set.of(DESTROYED, DEPLOYING),  // DEPLOYING 支持覆盖部署
    ERROR,     Set.of(DESTROYED, READY),      // READY 支持修复后重新部署
    DESTROYED, Set.of()                       // 终态
);
```

### 3.4 状态机图示

```
CREATING  → READY → DEPLOYING → RUNNING → DESTROYED
              ↘        ↘           ↘
               ERROR ← ERROR ← ERROR
```

### 3.5 状态与 Tool 的对应关系

| 状态 | 允许调用的 Tools | 禁止调用的 Tools |
|------|-----------------|-----------------|
| `CREATING` | `env_get_logs`（查看初始化日志） | `env_deploy_service`, `test_health_check`, `test_load` |
| `READY` | `env_deploy_service`, `env_destroy`, `env_get_logs` | `test_health_check`, `test_load`（无可部署服务） |
| `DEPLOYING` | `env_get_logs`（查看部署日志） | `env_deploy_service`（并发部署被锁） |
| `RUNNING` | `test_*`, `env_get_logs`, `env_destroy`, `env_deploy_service`（覆盖） | 无 |
| `ERROR` | `env_get_logs`（排查）, `env_destroy` | `env_deploy_service`（需先修复到 READY） |
| `DESTROYED` | 无 | 全部 |

### 3.6 创建规格

```java
public class EnvironmentSpec {
    private final String name;
    private final EnvironmentType environmentType;
    private final HostId hostId;
    private final IsolationType isolationType;
    private final String runtimeConstraint;
    private final ResourceQuota resourceQuota;
    private final LifecyclePolicy lifecyclePolicy;
}
```

## 4. DeployPipeline（部署流水线）— 聚合根

**身份标识**: `PipelineId`

**核心职责**: 作为 MCP 部署领域的**首选入口**，封装完整部署流水线的原子化编排。

### 4.1 领域模型

```java
package devops.dashboard.domain.mcp;

public class DeployPipeline {
    private final PipelineId id;
    private final DeploySpec spec;
    private final PipelineStatus status;
    private final List<PipelineStage> stages;
    private final EnvironmentId createdEnvId;
    private final Instant createdAt;
    private final Instant completedAt;

    public Mono<PipelineResult> execute() {
        return stageCreateEnv()
            .flatMap(this::stageDeployService)
            .flatMap(this::stageHealthCheck)
            .flatMap(this::stageNetworkVerify)
            .map(this::buildSuccessResult)
            .onErrorResume(this::compensate);
    }

    private Mono<PipelineResult> compensate(Throwable error) {
        if (createdEnvId != null && !spec.isKeepOnFailure()) {
            return envDestroy(createdEnvId)
                .thenReturn(buildFailureResult(error));
        }
        return Mono.just(buildFailureResult(error));
    }
}
```

### 4.2 值对象

```java
public class DeploySpec {
    private final String serviceName;         // 来自 ServiceRegistry 白名单
    private final HostId targetHostId;        // 来自 env_list / hosts://topology
    private final String version;             // 镜像标签或 Git tag
    private final IsolationType isolationType; // docker | native
    private final String runtimeConstraint;   // 如 "openjdk:21-jre-slim"
    private final List<String> verifyEndpoints; // 部署后验证的 HTTP 端点
    private final boolean keepOnFailure;      // 失败时是否保留环境用于排查
}

public enum PipelineStatus {
    PENDING, CREATING, DEPLOYING, VERIFYING, ANALYZING, SUCCEEDED, FAILED, COMPENSATED
}

public class PipelineStage {
    private final String name;               // "env_create" | "env_deploy" | "health_check" | "network_verify"
    private final StageStatus status;
    private final String output;
    private final Instant startedAt;
    private final Instant completedAt;
}

public enum StageStatus {
    PENDING, RUNNING, SUCCEEDED, FAILED, SKIPPED
}
```

## 5. LogAggregate（日志聚合）— 聚合根

**身份标识**: `LogQueryId`

**核心职责**: 作为 MCP 管理的指定环境的**唯一合法日志来源**，替代 SSH + `docker logs`。

### 5.1 领域模型

```java
package devops.dashboard.domain.mcp;

public class LogAggregate {
    private final LogQueryId id;
    private final EnvironmentId envId;       // 必须来自 env_list
    private final String serviceName;        // 可选，空表示整个环境聚合日志
    private final LogQuerySpec spec;

    public Flux<LogLine> stream() {
        validateEnvExists(envId);
        return logProvider.fetch(envId, serviceName, spec)
            .map(this::normalizeFormat)
            .map(this::desensitize);
    }
}
```

### 5.2 值对象

```java
public class LogQuerySpec {
    private final int tailLines;             // 默认 100
    private final String since;              // 如 '10m'、'1h'
    private final LogLevel minLevel;         // 最低日志级别过滤
}

public enum LogLevel {
    DEBUG, INFO, WARN, ERROR, FATAL
}

public class LogLine {
    private final Instant timestamp;
    private final LogLevel level;
    private final String service;
    private final String message;            // 脱敏后的消息
    private final String rawHash;            // 原始日志的哈希（用于审计追溯）
}
```

## 8. 异常分类

### 8.1 领域异常

| 层级 | 包 | 异常类 | 触发场景 |
|------|-----|--------|---------|
| **Pipeline** | `domain/mcp/` | `PipelineException` | 基类 |
| | | `PipelineStageFailedException` | deploy_pipeline 某阶段失败 |
| | | `PipelineCompensationException` | 补偿清理失败 |
| | | `ServiceNotRegisteredException` | serviceName 不在 ServiceRegistry |
| **Log** | `domain/mcp/` | `LogAggregateException` | 基类 |
| | | `LogQueryTimeoutException` | 日志查询超时 |
| **Environment** | `domain/environment/` | `InvalidEnvironmentTransitionException` | 状态转换非法 |
| | | `EnvironmentLockedException` | 分布式锁冲突 |
| | | `EnvironmentNotFoundException` | 环境不存在 |
| **Host** | `domain/host/` | `HostNotFoundException` | 主机不存在 |
| | | `InvalidHostRoleException` | 主机角色不匹配 |
| | | `HostCapabilityMismatchException` | 主机能力不匹配 |

### 8.2 MCP 错误映射

| 领域异常 | MCP Error Code | forbidden 示例 | nextSteps 示例 |
|----------|---------------|---------------|---------------|
| `HostNotFoundException` | `INVALID_PARAMS` | 禁止手动指定未注册节点 | `["env_list 查看可用宿主机"]` |
| `InvalidHostRoleException` | `INVALID_PARAMS` | 禁止向非 TARGET 节点部署 | `["env_list 筛选 roles 包含 target 的节点"]` |
| `HostCapabilityMismatchException` | `INVALID_PARAMS` | 禁止在不支持的主机上运行 | `["env_list 查看 capabilities"]` |
| `EnvironmentNotFoundException` | `INVALID_PARAMS` | — | `["env_list 确认环境 ID"]` |
| `InvalidEnvironmentTransitionException` | `INVALID_PARAMS` | 禁止绕过状态机直接操作 | `["env_list 确认状态", "env_get_logs 排查"]` |
| `EnvironmentLockedException` | `INVALID_PARAMS` | 禁止并发操作同一环境 | `["等待 30 秒后重试", "env_list 查看状态"]` |
| `ServiceNotRegisteredException` | `INVALID_PARAMS` | 禁止部署未注册服务 | `["检查 serviceName 拼写", "联系管理员注册"]` |

## 9. 设计约束总结

### 9.1 不变量规则

| 聚合根 | 不变量 | 校验时机 |
|--------|--------|---------|
| Host | parentId 引用必须存在 | 创建/更新时 |
| Host | hostRoles 与 capabilities 一致（LOADGEN → NATIVE） | 创建/更新时 |
| Environment | hostId 必须是 TARGET 角色 | 创建时 |
| Environment | isolationType 与 host capabilities 匹配 | 创建时 |
| Environment | 服务端口不冲突 | 部署服务时 |
| Environment | 资源不超配额 | 创建/扩展时 |
| Environment | 状态转换必须符合 VALID_TRANSITIONS | transitionTo 时 |
| Environment | DEPLOYING 状态必须持有分布式锁 | env_deploy_service 调用前 |
| DeployPipeline | serviceName 必须在 ServiceRegistry 中 | execute 前 |
| DeployPipeline | targetHostId 必须是 TARGET 角色 | execute 前 |
| LogAggregate | envId 必须存在于 env_list | stream 前 |
| ExperimentSession | 结论前必须有证据 | conclude 时 |
| ExperimentSession | 只能归档已结束的会话 | archive 时 |

### 9.2 跨聚合引用规则

- `DeployPipeline` → `Environment`: 通过 `EnvironmentId` 引用
- `DeployPipeline` → `Host`: 通过 `HostId` 引用
- `LogAggregate` → `Environment`: 通过 `EnvironmentId` 引用
- `ExperimentSession` → `Environment`: 通过 `EnvironmentId` 引用
- **禁止**: 直接持有其他聚合根的对象引用
