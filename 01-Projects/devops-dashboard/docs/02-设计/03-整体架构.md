## 2. 分层职责

| 层级 | 职责 | 禁止 |
|------|------|------|
| **MCP Server** | 协议适配、参数校验、结果格式化、Prompt 管理、错误翻译 | 直接操作基础设施、直接访问数据库 |
| **Application Service** | 用例编排、事务边界、跨聚合协调、状态机驱动 | 包含业务规则细节 |
| **Domain** | 业务规则、状态机、不变量保护、聚合根行为 | 依赖框架/技术细节 |
| **Infrastructure** | 技术实现、外部系统集成、配置解析 | 包含业务逻辑 |

### 防腐层（ACL）关键映射

| 外部 Schema 词汇                       | 内部领域词汇                                   | 映射位置                               |
| ---------------------------------- | ---------------------------------------- | ---------------------------------- |
| `type` (env_create)                | `isolationType`                          | EnvironmentHandler#buildSpec       |
| `serviceName` (env_deploy_service) | `templateName` (兼容) / `serviceName` (目标) | EnvDeployRequest / ServiceManifest |
| `runtime` (env_create)             | `runtimeConstraint` + `isolationType`    | EnvironmentHandler#buildSpec       |

## 3. 核心概念模型

### 3.1 Host（主机节点）

```java
public class Host {
    private final HostId id;
    private final HostType hostType;       // PVE_HYPERVISOR, VM, BARE_METAL, LOCAL
    private final HostId parentId;         // null if root
    private final String label;
    private final NetworkZone networkZone;
    private final Set<Capability> capabilities; // DOCKER, NATIVE, VM
    private final Set<HostRole> hostRoles; // MCP_HOST, TARGET, LOADGEN
    private final ResourceCapacity resources;
    private final AccessInfo access;
    private final HostStatus status;
}
```

### 3.2 Environment（环境）

```java
public class Environment {
    private final EnvironmentId id;
    private final HostId hostId;
    private final EnvironmentType environmentType;  // DEV, TEST, STAGING, PROD, EXPERIMENT
    private final IsolationType isolationType;      // DOCKER, NATIVE
    private final String runtimeConstraint;         // "docker:26.0", "openjdk:21-jre-slim"
    private final EnvironmentStatus status;
    private final List<ServiceInstance> services;
    private final ResourceQuota resourceQuota;
    private final LifecyclePolicy lifecyclePolicy;
}
```

### 3.3 DeployPipeline（部署流水线）

```java
public class DeployPipeline {
    private final PipelineId id;
    private final DeploySpec spec;
    private final PipelineStatus status;
    private final List<PipelineStage> stages;
    private final EnvironmentId createdEnvId;

    public Mono<PipelineResult> execute() { /* Saga 协调 */ }
    private Mono<PipelineResult> compensate(Throwable error) { /* 失败回滚 */ }
}
```

## 5. 安全边界表

| 操作 | 是否需要确认 | 危险等级 | 原因 |
|------|-------------|---------|------|
| `hosts://topology` | 否 | 安全 | 只读查询 |
| `templates://list` | 否 | 安全 | 只读查询 |
| `env_list` | 否 | 安全 | 只读查询 |
| `env_create` | 是 | 中等 | 占用 Target Host 资源 |
| `env_deploy_service` | 是 | 中等 | 变更端口/资源分配 |
| `env_destroy` | 是 + 二次确认 | 高危 | 不可逆，数据丢失 |
| `test_health_check` | 否 | 安全 | 只读探测 |
| `test_load` | 是 | 中等 | 消耗目标端和压测端资源 |
| `test_exec_command` | 是 | 高危 | 任意命令执行风险 |
| `analyze_network_path` | 否 | 安全 | 只读分析 |
| `deploy_pipeline` | 是 | 中等 | 内部包含 env_create + deploy |
