## 📋 使用说明

### 如何使用此清单

1. **勾选进度**: 每完成一个任务，将 `[ ]` 改为 `[x]`
2. **记录时间**: 在"实际耗时"列填写实际花费的时间
3. **跟踪阻塞**: 如有依赖未完成，在"备注"栏标注
4. **每日站会**: 基于此清单同步进度

### 图例说明

| 符号 | 含义 |
|------|------|
| `[ ]` | 未开始 |
| `[~]` | 进行中 |
| `[x]` | 已完成 |
| `[!]` | 被阻塞 |
| `P0` | 必须完成（阻塞后续任务） |
| `P1` | 重要（影响功能完整性） |
| `P2` | 可选（优化/增强） |
