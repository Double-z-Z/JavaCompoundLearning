## [1.2.0] - 2026-05-26

### ✨ 新增 (Added)

- **Pipeline 前置校验阶段**: deploy_pipeline 在 Saga 编排前执行 fail-fast 校验（服务注册、主机可达、能力匹配、SSH 连通性），失败时返回 `PRECONDITION_FAILED` + 可操作的 nextSteps
- **主机健康状态细化**: 新增 `UNREACHABLE`、`DEGRADED` 状态，env_list 可区分"SSH 不通"与"未探测"
- **服务模板配置**: 新增 `ServiceTemplatesConfig`，健康检查端口从模板读取而非硬编码
- **keepOnFailure 参数**: deploy_pipeline 暴露 `keepOnFailure` 参数，支持失败时保留环境现场排查

### 🔧 修复 (Fixed)

- **错误传播链路**: deployService 失败时不再吞没异常，Saga 可正确感知并触发补偿
- **主机 SSH 认证**: Redis 集群 VM 的 SSH 用户从 root 修正为 redis
- **健康检查 URL**: test_health_check / test_load 将 hostId 解析为 IP 地址

### 📝 文档 (Docs)

- 边界约束文档更新：Pipeline 三阶段模型 + keepOnFailure 补偿规则
- 架构文档更新：HostHealthStatus 状态机
- 服务模板库：新增 redis-counter-service 条目

## [1.0.0] - 2026-05-19

### ✨ 新增 (Added)

#### 核心功能
- **环境管理 CRUD API**
  - `POST /api/v1/environments` - 创建环境（支持自定义名称、类型、资源配额）
  - `GET /api/v1/environments` - 查询环境列表（支持状态筛选）
  - `GET /api/v1/environments/{id}` - 查询环境详情
  - `DELETE /api/v1/environments/{id}` - 销毁环境

- **领域模型层** (DDD)
  - Environment 聚合根（含完整状态机：CREATING → RUNNING → STOPPED → DESTROYED/FAILED）
  - ServiceInstance 实体（服务实例生命周期管理）
  - 值对象: ResourceQuota, LifecyclePolicy, TargetNodeRef, PortMapping, HealthCheckConfig

- **数据持久层**
  - EnvironmentRepository (Spring Data JPA)
  - ExperimentRepository (预留)
  - ServiceInstanceRepository

- **业务逻辑层**
  - EnvironmentService 接口 + EnvironmentServiceImpl 实现
  - 环境创建、销毁、服务部署、状态查询等核心方法

- **API 文档**
  - Swagger/OpenAPI 3.0 自动文档（WebFlux 版本）
  - 完整的 API 使用指南 (`docs/api-guide.md`)

- **测试体系**

    - EnvironmentServiceImplTest: Service 层 Mock 测试（8个）

- **异常处理**
  - GlobalExceptionHandler 全局异常处理器
  - 16 个独立异常类（从合并文件拆分）

#### 文档

#### 配置与工具链

- Maven Enforcer Plugin（防止 Tomcat 依赖复发）
- pom.xml 详细注释说明所有关键决策

### 🔧 变更 (Changed)

#### 技术架构
- **WebFlux 模式**: 确保项目运行在 Netty 而非 Tomcat
- **JPA 加载策略**: 所有集合字段改为 EAGER（解决 WebFlux 异步 Session 问题）
- **ID 类重构**: EnvironmentId/ExperimentId 改为独立 @Embeddable 类（修复 JPA 兼容性）
- **值对象序列化**: Evidence/Hypothesis/Conclusion 使用 @JdbcTypeCode(JSON) 处理嵌套集合

#### Bug 修复
- ✅ 修复 Tomcat 替代 Netty 启动问题（排除 3 个间接依赖源）
- ✅ 修复 Swagger UI 404 问题（删除 webflux.base-path 干扰）
- ✅ 修复 JPA @EmbeddedId 不识别问题
- ✅ 修复 LazyInitializationException（EAGER 加载）
- ✅ 修复 NPE 创建环境（targetNodes null 安全处理）
- ✅ 修复 name 参数丢失（Service 接口增加 name 参数）
- ✅ 修复 GlobalExceptionHandler 缺失导致 404 错误格式不统一

### 🗑️ 移除 (Removed)

- 删除 WebFluxConfig.java（WebFlux 自动配置足够，避免与 WebMVC 冲突）
- 移除 application.yml 中的 webflux.base-path（干扰 SpringDoc 路由）

### 🔒 安全 (Security)

- 当前版本无认证机制（Phase 4 将添加 JWT/OAuth2）
- 开发模式 Portainer 关闭认证（生产环境必须开启！）

## 📌 版本规范说明

### 语义化版本 (Semantic Versioning)

```
MAJOR.MINOR.PATCH

MAJOR:   不兼容的 API 变更（如重写整个 REST API）
MINOR:   向后兼容的功能新增（如新增 Experiment 模块）
PATCH:   向后兼容的问题修复（如修复 Bug、优化性能）
```

### 当前版本: v1.0.0-SNAPSHOT

**原因**: Phase 1 是基础骨架，后续会有较大改动：
- Phase 2 可能调整 API 结构（如加入 Provider 调用）
- Phase 3 会新增 WebSocket 端点
- 正式发布时会变为 v1.0.0（或根据实际变更升级主版本号）
