## 1. Host 层设计（新增）

### 1.1 领域模型

```java
package devops.dashboard.domain.host;

public class Host {
    private final HostId id;
    private final HostType type;
    private final HostId parentId;          // null for root nodes
    private final String label;
    private final NetworkZone networkZone;
    private final Set<Capability> capabilities;
    private final Set<HostRole> roles;
    private final ResourceCapacity resources;
    private final AccessInfo access;
    private final Set<LoadgenTool> loadgenTools;
    private final HostStatus status;
    private final Instant lastHeartbeat;

    // 业务方法
    public boolean isTarget() { return roles.contains(HostRole.TARGET); }
    public boolean isLoadgen() { return roles.contains(HostRole.LOADGEN); }
    public boolean isMcpHost() { return roles.contains(HostRole.MCP_HOST); }
    public boolean supportsDocker() { return capabilities.contains(Capability.DOCKER); }
    public boolean supportsNative() { return capabilities.contains(Capability.NATIVE); }

    public boolean hasParent(HostId candidate) {
        return candidate.equals(this.parentId);
    }

    public boolean isSibling(Host other) {
        if (this.parentId == null || other.parentId == null) return false;
        return this.parentId.equals(other.parentId);
    }
}

public class ResourceCapacity {
    private final int cpuTotal;           // cores
    private final int memTotalMb;
    private final int diskTotalGb;
    private final int cpuFree;            // dynamically updated
    private final int memFreeMb;

    public boolean canAccommodate(ResourceQuota required) {
        // 校验逻辑
    }
}

public class AccessInfo {
    private final String sshHost;
    private final int sshPort;
    private final String user;
    private final String keyPath;         // SSH key
    private final String password;        // fallback, nullable
}

public enum LoadgenTool {
    WRK, HEY, AB, JMETER, K6
}
```

### 1.2 拓扑分析领域服务

```java
package devops.dashboard.domain.host;

public class NetworkPathAnalyzer {

    public NetworkPath analyze(Host source, Host target, int targetPort) {
        // 同机判断
        if (source.getId().equals(target.getId())) {
            return NetworkPath.sameHost(source, target, targetPort);
        }

        // 同 PVE 宿主机判断
        if (source.isSibling(target) && source.getType() == HostType.VM) {
            return NetworkPath.sameHypervisor(source, target, targetPort);
        }

        // 同网络区域
        if (source.getNetworkZone().equals(target.getNetworkZone())) {
            return NetworkPath.sameLan(source, target, targetPort);
        }

        // 跨网络
        return NetworkPath.wan(source, target, targetPort);
    }
}

public class NetworkPath {
    private final HostId sourceId;
    private final HostId targetId;
    private final int targetPort;
    private final PathType pathType;
    private final int estimatedHops;
    private final double estimatedRttMs;
    private final boolean goesThroughBridge;
    private final boolean physicalNicInvolved;
    private final String warning;         // 可信度提示

    public enum PathType {
        SAME_HOST("同机"),
        SAME_HYPERVISOR("同虚拟化宿主机"),
        SAME_LAN("同局域网"),
        WAN("跨网络");

        private final String displayName;
    }
}
```

## 2. Environment 层增强

### 2.1 增强点

Environment 聚合根增加 `hostId` 字段，明确归属。

```java
package devops.dashboard.domain.environment;

public class Environment {
    private final EnvironmentId id;
    private final HostId hostId;            // 新增：绑定到 Target Host
    private final RuntimeType runtime;      // 新增：DOCKER | NATIVE
    // ... 其他字段保持不变
}

public enum RuntimeType {
    DOCKER,     // 通过 Docker Compose / Docker API 部署
    NATIVE      // 直接在 Host 上运行进程（如 systemd、直接二进制）
}
```

### 2.2 创建规格增强

```java
public class EnvironmentSpec {
    private final String name;
    private final EnvironmentType type;
    private final HostId hostId;            // 新增：必须指定
    private final RuntimeType runtime;        // 新增：默认 DOCKER
    private final ResourceQuota resourceQuota;
    private final LifecyclePolicy lifecyclePolicy;
    private final List<ServiceManifest> services;
}
```

### 2.3 服务部署时的 Host 校验

```java
@Service
public class EnvironmentService {

    public Mono<Environment> createFromSpec(EnvironmentSpec spec) {
        // 1. 校验 hostId 存在且为 TARGET 角色
        Host host = hostRepository.findById(spec.getHostId())
            .orElseThrow(() -> new HostNotFoundException(spec.getHostId()));

        if (!host.isTarget()) {
            throw new InvalidHostRoleException(spec.getHostId(), "目标主机必须是 TARGET 角色");
        }

        // 2. 校验 runtime 与 host capabilities 匹配
        if (spec.getRuntime() == RuntimeType.DOCKER && !host.supportsDocker()) {
            throw new HostCapabilityMismatchException(spec.getHostId(), "DOCKER");
        }

        // 3. 校验资源充足
        if (!host.getResources().canAccommodate(spec.getResourceQuota())) {
            throw new ResourceQuotaExceededException(spec.getHostId());
        }

        // 4. 委托 InfrastructureProvider 执行
        return infrastructureProvider.provision(spec)
            .map(env -> environmentRepository.save(env));
    }
}
```

### 3.4 实现：SSH 远程执行

```java
package devops.dashboard.infrastructure.loadgen;

@Service
public class SshLoadgenService implements LoadgenService {

    private final HostRepository hostRepository;
    private final SshCommandExecutor sshExecutor;  // 现有组件

    @Override
    public Mono<LoadTestResult> executeLoadTest(LoadTestSpec spec) {
        Host host = hostRepository.findById(spec.getLoadgenHostId())
            .orElseThrow(() -> new HostNotFoundException(spec.getLoadgenHostId()));

        if (!host.isLoadgen()) {
            throw new InvalidHostRoleException(spec.getLoadgenHostId(), "LOADGEN");
        }

        String command = buildWrkCommand(spec);

        return sshExecutor.execute(host.getAccess(), command, spec.getDuration().plusSeconds(10))
            .map(this::parseWrkOutput);
    }

    private String buildWrkCommand(LoadTestSpec spec) {
        StringBuilder cmd = new StringBuilder("wrk");
        cmd.append(" -t").append(Math.min(spec.getConnections(), 12));  // threads
        cmd.append(" -c").append(spec.getConnections());                // connections
        cmd.append(" -d").append(spec.getDuration().getSeconds()).append("s");

        if (spec.getRpsLimit().isPresent()) {
            cmd.append(" -R").append(spec.getRpsLimit().getAsInt());    // rate limit
        }

        if (spec.getMethod() == HttpMethod.POST && spec.getPayload().isPresent()) {
            // wrk 需要 lua 脚本处理 POST body，简化版用 hey 替代
        }

        cmd.append(" ").append(spec.getTargetUrl());
        return cmd.toString();
```

## 5. MCP 适配层设计

### 5.1 架构位置

MCP 适配层是 **Application Service 之上的薄层**，负责：
1. 将 MCP Protocol 的 Tool/Resource 调用翻译为 Application Service 方法调用
2. 参数校验与转换
3. 结果格式化（JSON）
4. 错误映射（DomainException → MCP Error）

### 5.2 包结构

```
devops.dashboard.mcp
├── server
│   └── DevOpsMcpServer.java          // @Component，注册 Tools/Resources/Prompts
├── handler
│   ├── DiscoveryHandler.java         // hosts://*, templates://*
│   ├── EnvironmentHandler.java       // env_*
│   ├── TestingHandler.java           // test_*
│   ├── DiagnosisHandler.java         // analyze_*, stream_logs, exec_command
│   └── EvidenceHandler.java          // session_*, evidence_*
├── mapper
│   └── McpResponseMapper.java        // 领域对象 → MCP JSON
└── prompt
    ├── ExperimentWizardPrompt.java
    ├── OpsTroubleshooterPrompt.java
    └── NetworkAwarenessPrompt.java
```

### 5.3 Server 注册入口

```java
package devops.dashboard.mcp.server;

@Component
public class DevOpsMcpServer {

    private final McpSyncServer syncServer;  // MCP SDK

    public DevOpsMcpServer(
            DiscoveryHandler discovery,
            EnvironmentHandler environment,
            TestingHandler testing,
            DiagnosisHandler diagnosis,
            EvidenceHandler evidence) {

        // 注册 Resources (只读)
        syncServer.addResource(discovery.getHostsTopologyResource());
        syncServer.addResource(discovery.getTemplatesListResource());
        syncServer.addResource(discovery.getEnvsListResource());

        // 注册 Tools (写操作)
        syncServer.addTool(environment.getCreateTool());
        syncServer.addTool(environment.getDeployServiceTool());
        syncServer.addTool(environment.getDestroyTool());
        syncServer.addTool(environment.getAccessTool());

        syncServer.addTool(testing.getHealthCheckTool());
        syncServer.addTool(testing.getFunctionalTool());
        syncServer.addTool(testing.getLoadTool());
        syncServer.addTool(testing.getCollectMetricsTool());
        syncServer.addTool(testing.getStreamLogsTool());
        syncServer.addTool(testing.getExecCommandTool());

        syncServer.addTool(diagnosis.getAnalyzeNetworkPathTool());

        syncServer.addTool(evidence.getSessionCreateTool());
        syncServer.addTool(evidence.getSessionConcludeTool());
        syncServer.addTool(evidence.getSubmitEvidenceTool());

        syncServer.addPrompt(new ExperimentWizardPrompt());
        syncServer.addPrompt(new OpsTroubleshooterPrompt());
        syncServer.addPrompt(new NetworkAwarenessPrompt());
    }
```

## 6. 异常映射层

MCP Server 需要将领域异常转换为 MCP 标准错误，附带中文提示。

| 领域异常 | MCP Error Code | 用户提示 |
|---------|---------------|---------|
| `HostNotFoundException` | `INVALID_PARAMS` | "指定的主机不存在，请先通过 hosts://topology 查询可用节点" |
| `InvalidHostRoleException` | `INVALID_PARAMS` | "主机 {id} 不具备 {role} 角色，无法执行此操作" |
| `HostCapabilityMismatchException` | `INVALID_PARAMS` | "主机不支持 {capability} 运行时" |
| `ResourceQuotaExceededException` | `INVALID_PARAMS` | "主机资源不足，当前空闲 CPU {cpu} / 内存 {mem}MB" |
| `EnvironmentNotFoundException` | `INVALID_PARAMS` | "环境不存在" |
| `PortConflictException` | `INTERNAL_ERROR` | "端口冲突，建议更换端口或销毁占用环境" |
| `LoadgenToolNotAvailableException` | `INVALID_PARAMS` | "压测机未安装 {tool}，可用工具: {available}" |
| `CommandExecutionException` | `INTERNAL_ERROR` | "远程命令执行失败: {detail}" |

```java
package devops.dashboard.mcp.error;

public class McpExceptionTranslator {

    public McpError translate(DomainException ex) {
        return switch (ex) {
            case HostNotFoundException e -> McpError.invalidParams("主机不存在: " + e.getHostId());
            case InvalidHostRoleException e -> McpError.invalidParams(
                String.format("主机 %s 不具备 %s 角色", e.getHostId(), e.getRequiredRole()));
            case ResourceQuotaExceededException e -> McpError.invalidParams(
                String.format("主机 %s 资源不足", e.getHostId()));
            default -> McpError.internalError(ex.getMessage());
        };
    }
}
```
