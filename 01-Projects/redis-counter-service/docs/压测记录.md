## 瓶颈分析

### 性能基线

| 测试路径 | QPS | 说明 |
|---------|-----|------|
| Redis 单机上限 | ~200,000 | 理论值 |
| PVE 内部 → Redis | ~155,000-171,000 | 真实上限 |
| WSL → Redis (NAT) | ~43,000 | 受网络路径限制 |
| WSL → HTTP → Redis | ~22,000-40,000 | +应用层开销 |

### 瓶颈分层

```
外部压测瓶颈分解：

第一层：NAT 转换和路由器（WSL → PVE 内部）
        43k vs 155k = 3.6x 性能损失

第二层：应用层（HTTP + JSON + Lettuce）
        22k vs 43k = 2x 性能损失
```

## 命令速查

### 初始化库存
```bash
curl -X POST http://10.0.0.142:8080/stock/SKU001/init?quantity=1000000000
```

### HTTP 压测
```bash
# post.lua 需要先创建
echo 'wrk.method = "POST"' > ~/workspace/post.lua

# 压测
wrk -t4 -c100 -d30s -s ~/workspace/post.lua http://10.0.0.142:8080/stock/SKU001/decrement?quantity=1
```
