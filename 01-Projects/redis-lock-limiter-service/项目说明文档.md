# Redis Lock Limiter Service

> 分布式锁与限流系统 — 基于 Redis 的生产级实现

## 项目概述

本项目实现了一个**高可靠、高性能**的分布式锁与限流服务，基于 Redis 提供：

- **分布式锁**：SET NX EX + Lua 脚本，支持可重入、看门狗续期
- **三种限流器**：固定窗口、滑动窗口、令牌桶

## 核心功能

| 功能 | 描述 |
|------|------|
| 基础分布式锁 | 原子加锁、防误删、TTL 过期 |
| 固定窗口限流 | String + INCR，简单高效，有边界穿透 |
| 滑动窗口限流 | ZSet + ZCARD，精确无穿透 |
| 令牌桶限流 | Hash + 令牌补充，支持突发流量 |

## API 接口

### 分布式锁 API

```bash
# 获取锁
curl -X POST http://localhost:8080/api/lock/acquire \
  -H "Content-Type: application/json" \
  -d '{"key": "order:123", "ttlSeconds": 30}'

# 释放锁
curl -X POST http://localhost:8080/api/lock/release \
  -H "Content-Type: application/json" \
  -d '{"key": "order:123"}'

# 查询锁状态
curl http://localhost:8080/api/lock/status/order:123
```

### 限流 API

```bash
# 滑动窗口限流（精确）
curl -X POST http://localhost:8080/api/limiter/sliding \
  -H "Content-Type: application/json" \
  -d '{"key": "user:12345", "limit": 100, "windowSeconds": 60}'

# 固定窗口限流（高性能）
curl -X POST http://localhost:8080/api/limiter/fixed \
  -H "Content-Type: application/json" \
  -d '{"key": "user:12345", "limit": 100, "windowSeconds": 60}'

# 令牌桶限流（支持突发）
curl -X POST http://localhost:8080/api/limiter/token \
  -H "Content-Type: application/json" \
  -d '{"key": "user:12345", "capacity": 100, "ratePerSec": 10}'

# 统一接口（默认滑动窗口）
curl -X POST http://localhost:8080/api/limiter/check \
  -H "Content-Type: application/json" \
  -d '{"key": "user:12345", "limit": 100, "windowSeconds": 60}'
```

### 响应示例

```json
{
  "success": true,
  "lockKey": "order:123",
  "ttl": 30
}
```

限流响应：

```json
{
  "allowed": true,
  "remaining": 99,
  "resetAt": 1715856000,
  "algorithm": "sliding_window"
}
```

被限流时返回 HTTP 429。

## 三种限流策略对比

| 策略 | 数据结构 | 突发支持 | 边界穿透 | 适用场景 |
|------|---------|---------|---------|---------|
| 固定窗口 | String | ❌ | ✅ 有 | 内部服务保护 |
| 滑动窗口 | ZSet | ❌ | ❌ 无 | API 精确限流 |
| 令牌桶 | Hash | ✅ | ❌ 无 | 下载限速、支付并发 |
