# Sentinel 熔断机制

## 一句话定义
Sentinel 熔断机制是在**服务调用链路中，当错误率或慢调用比例超过阈值时，自动切断对下游服务的请求**，防止故障扩散的自我保护策略。

## 核心理解

### 熔断器三种状态

```
关闭 (Closed) ──错误率↑──▶ 打开 (Open) ──超时后──▶ 半开 (Half-Open)
    ▲                                              │
    └─────────── 请求成功 ─────────────────────────┘
```

| 状态 | 行为 | 触发条件 |
|------|------|---------|
| **关闭** | 正常放行请求 | 默认状态，持续统计错误率 |
| **打开** | 快速失败，拒绝请求 | 错误率/慢调用比例超过阈值 |
| **半开** | 放行少量探测请求 | 熔断超时后，试探恢复 |

### 熔断策略

1. **慢调用比例**：响应时间超过阈值的比例
2. **错误比例**：异常请求占总请求的比例
3. **错误计数**：异常请求绝对数
