# 客户端负载均衡（Client-Side Load Balancing）

## 一句话定义
客户端从注册中心获取服务实例列表后，在本地选择调用目标，无需经过额外的网关层进行路由分发。

## 核心理解

### 为什么是"客户端"而非"服务端"？

```
【服务端负载均衡】（如 Nginx）
  客户端 → Nginx ──分发──▶ A/B/C 实例
  特点：集中式、所有流量经过网关

【客户端负载均衡】（Spring Cloud 默认）
  客户端（本地有服务列表）→ 自己选一个实例调用
  特点：分布式、直连目标实例
```

**选择客户端负载均衡的原因**：
1. 注册中心已经把列表给你了 → 本地选择更高效
2. 减少网络跳数（少一跳 = 低延迟）
3. 避免网关成为瓶颈

### 负载均衡策略

| 策略 | 描述 | 适用场景 |
|------|------|---------|
| **Random** | 随机选择 | 实例性能相近时 |
| **Round-Robin** | 轮流选择 | 需要均匀分配请求 |
| **Weighted** | 按权重分配 | 实例配置不同时 |
| **Least Connections** | 选择连接数最少的 | 长连接场景 |

**Spring Cloud 实现**：
- 旧版：Ribbon（已废弃）
- 新版：Spring Cloud LoadBalancer（默认）

### 与 API Gateway 的关系

```
完整架构：

浏览器/前端
    │
    ▼
┌─────────┐
│API Gateway│ ← 服务端 LB（统一入口、认证、限流）
└────┬────┘
     │ （Gateway 也是微服务的"客户端"）
     ▼
┌─────────┐   注册中心   ┌─────────┐
│ 订单服务  │◀──订阅──▶ │ 商品服务  │
└─────────┘            └─────────┘
    ▲                        ▲
    └──── 客户端 LB 直连 ──────┘
```

> **关键洞察**：
> - 外部用户请求 → 经过 Gateway（服务端 LB）
> - 服务间调用 → 客户端 LB 直连（不经过 Gateway）
> - Sentinel 在**客户端侧**做限流熔断 → 不管从哪来都能控制

## 关键关联

- [[Sentinel-核心机制]] - 关联原因：Sentinel 在客户端侧执行限流和熔断，与服务发现解耦但协同工作——即使注册中心返回的列表有延迟，Sentinel 也能保护系统。
- [[服务注册与发现]] - 关联原因：客户端负载均衡依赖注册中心提供的服务实例列表。
- [[Nacos架构与Distro协议]] - 关联原因：Distro 的 AP 设计允许短暂不一致，客户端 LB 配合本地缓存 + Sentinel 兜底实现高可用。

## 我的误区与疑问

- ❌ **误区**：以为所有请求都经过 Gateway → **纠正**：只有外部用户请求经过 Gateway，服务间调用用客户端 LB 直连
- ❓ **疑问**：如果某个实例响应慢但不挂，客户端 LB 能感知到吗？还是只靠心跳？
- 💡 **待验证**：Spring Cloud LoadBalancer 如何处理实例健康状态的实时更新？

## 代码与实践

```java
// Spring Cloud LoadBalancer 使用示例
@Service
public class OrderService {
    
    @Autowired
    private LoadBalancerClient loadBalancerClient;
    
    @Autowired
    private RestTemplate restTemplate;
    
    public String callProductService() {
        // 方式1：手动选择
        ServiceInstance instance = loadBalancerClient.choose("product-service");
        String url = instance.getUri() + "/products";
        return restTemplate.getForObject(url, String.class);
        
        // 方式2：使用 @LoadBalanced 注解（推荐）
        // restTemplate.getForObject("http://product-service/products", String.class);
    }
}
```

```java
// 配置 RestTemplate 为负载均衡模式
@Configuration
public class RestConfig {
    
    @Bean
    @LoadBalanced  // ← 关键注解
    public RestTemplate restTemplate() {
        return new RestTemplate();
    }
}
```
