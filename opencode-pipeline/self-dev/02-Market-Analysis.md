# OpenCode Pipeline Orchestrator — 市场选型与竞品分析

## 1. 目标市场定位

个人开发者 / 小型技术团队的 **AI 原生工作流编排工具**。不是替代 IDE，而是叠加在 AI 编程工具之上的**控制塔层**。

## 2. 竞品分析

### 2.1 Hermes（已验证，放弃）

| 维度 | 评估 | 结论 |
|------|------|------|
| 架构一致性 | Developer 与用户的讨论对 Architect/Reviewer 不可见 | ❌ 致命缺陷 |
| 流程控制 | 用户需手动控制流转，监控中断消耗注意力 | ❌ 阻碍并行 |
| 模型绑定 | 角色绑死模型，缺乏灵活性 | ⚠️ 可接受 |
| 开源性 | 开源 | ✅ |
| 最终判定 | **放弃**，核心问题不可通过配置解决 | — |

### 2.2 Claude Code（参考标杆）

| 维度 | 评估 | 结论 |
|------|------|------|
| 速度 | 最快，比 OpenCode 快 45%-78% | ✅ |
| 输出质量 | 较快但 thoroughness 不足（测试覆盖少） | ⚠️ |
| 模型锁定 | 仅支持 Claude 系列 | ❌ |
| 闭源性 | 完全闭源 | ❌ 无法自定义工作流 |
| 工作流 | 无原生多阶段编排 | ❌ |
| 最终判定 | **参考 UI 体验**，但无法作为基础平台 | — |

### 2.3 Trae（当前主力 IDE）

| 维度 | 评估 | 结论 |
|------|------|------|
| 定位 | IDE + AI 助手 | ✅ 日常编码 |
| 远程开发 | 支持 SSH 远程 | ✅ 符合当前架构 |
| 工作流编排 | 无原生多 Agent 顺序编排 | ❌ |
| 模型支持 | 内置模型，有限自定义 | ⚠️ |
| 最终判定 | **保留作为 IDE**，但编排层需自建 | — |

### 2.4 OpenCode（选定基础平台）

| 维度 | 评估 | 结论 |
|------|------|------|
| 开源性 | 完全开源（MIT），160K+ Stars | ✅ |
| 模型支持 | 75+ 提供商，本地模型 | ✅ |
| 速度 | 比 Claude Code 慢 45%-78% | ⚠️ 可优化 |
| 验证策略 | 更严格（全量测试、依赖检查） | ✅ 长期可维护 |
| 多前端 | CLI / VS Code / 桌面 / Web | ✅ |
| 插件生态 | 25+ Hooks，可扩展 | ✅ |
| 工作流编排 | 无原生状态机，需自建 | ❌ 本项目要填补的空白 |
| 最终判定 | **选定为基础平台**，在其上构建 Sidecar 编排层 | — |

## 3. 技术选型决策

### 3.1 编排引擎：自建 Sidecar（Python/FastAPI）

- **不选 OpenCode 插件**：插件生命周期绑定 OpenCode 进程，无法跨会话持久化审批状态
- **不选独立应用**：Tauri 控制塔是最终 UI，但编排核心必须是常驻后台服务
- **选定 FastAPI Sidecar**：轻量、异步、HTTP API 友好，与 OpenCode 通过 CLI + 文件系统解耦

### 3.2 UI 层：HTML MVP → Tauri 桌面

| 阶段 | 形态 | 原因 |
|------|------|------|
| MVP | 单页 HTML | 30 分钟可验证核心机制 |
| V0.2 | Tauri 三 pane | 系统通知、全局快捷键、内嵌终端 |
| V0.3 | VS Code 扩展备选 | 不离开 IDE 的备选入口 |

### 3.3 模型路由策略

| 任务类型 | 推荐模型 | 成本策略 |
|---------|---------|---------|
| 架构设计 | DeepSeek Reasoner / Claude Opus | 高成本，低频 |
| 编码实现 | DeepSeek V4 Flash / GPT-5.2 | 中成本，中频 |
| 代码审查 | Kimi Coding / MiniMax M3 | 中成本，低频 |
| 快速探索 | 本地 Ollama (Qwen 2.5) | 零成本，高频 |
| 提交信息生成 | 本地模型 | 零成本，高频 |

### 3.4 部署架构

```
Windows 笔记本 (Tauri UI / 浏览器)
    ↓ HTTP/WebSocket (局域网)
PVE Fedora 虚拟机 (Sidecar + OpenCode)
    ↓ 本地进程
OpenCode CLI (多会话 Agent)
    ↓ API
DeepSeek / MiniMax / Kimi / Ollama
```

## 4. 关键决策记录

| 决策 | 选项 A | 选项 B | 选择 | 理由 |
|------|--------|--------|------|------|
| 编排引擎位置 | OpenCode 插件 | 独立 Sidecar | **B** | 跨会话持久化、故障隔离 |
| UI 入口 | 纯 Web | Tauri + Web 备选 | **Tauri** | 系统通知、内嵌终端 |
| 交互式 Stage | PTY 内嵌 | 暂停指引 | **待决策** | PTY 体验好但实现重 |
| 产物传递 | 文件系统 | 内存/数据库 | **文件系统** | 简单、可审计、与 Git 集成 |
| 配置存储 | .env | secrets.json | **secrets.json** | OpenCode 不读取 .env |
